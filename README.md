## 技术栈

- **前端**：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS 4
- **数据**：localStorage Mock（`kb_*` 键），服务层 + `useSyncExternalStore` 订阅
- **后端**：NestJS 12 + Prisma 6 + PostgreSQL（Docker），当前仅 `/health`
- **部署**：Vercel（前端）+ 阿里云（后端），前端经 `/api/*` 服务端反代调用后端

## 快速开始

```bash

```

## 功能模块

**首次体验与访客迁移**（`src/lib/guest/`）：访客会话 7 天 TTL；previewEngine 生成轻量结果，目标匹配按 exact/province_only 分级（地区/学段/年份/批次不符不误匹配）；考情未核对时给信息查找任务或标注明确的通用起步建议，不编造科目日期；登录迁移设支持门禁——未核对/往年目标不生成 7 天计划，已支持目标继承官方（official）结论，迁移幂等。

**目标确认**（`src/lib/targets/`）：四种目标状态入口；门禁规则统一在 domain 层，不满足时 `/plan`、`/today` 显示空状态，不生成假精确计划；多目标切换/归档/重新启用。

**考情证据**（`src/lib/evidence/`）：公告提交（链接/文本/文件占位）→ 异步提取 → 11 字段证据卡；AI 结论只能是"AI已提取/待审核"，"已从官方公告核对"仅来自人工审核；无来源/冲突/缺失显示"待确认"。

**资料与准备情况**（`src/lib/materials/`）：资料三状态入口、私有资料 CRUD、准备情况自评；诊断规则层给出继续/部分/暂缓结论与缺口清单（地区/学段/年份匹配、多套取舍、每周 <8h 时间收缩）。

**资源匹配**（`src/lib/resources/`）：五层流水线（模块候选→合规闸门→适用范围→权利层级排序→每缺口最多 3 条）；停用/权利不明/过期资源不强推。

**计划与执行**（`src/lib/plans/`）：PlanEngine 生成 7 天计划（每天 ≤3 核心任务、总时长 ≤ 可用时间、每天 1 项最低任务），每项任务含五要素（做什么/用什么资料/预计多久/怎样算完成/为什么先做），任务时长只向下压缩、复盘任务也有可打开的资料入口；草稿→确认→版本历史；今日反馈一任务一条、防重复——重复提交不触发计划版本增殖，反馈按任务 id 跨计划版本读取，重登后按持久化 isCurrent 找回计划；ReplanEngine 处理七类触发信号（保留/缩减/顺延/替换/放弃），未完成后无需重填资料、明日安排不过量、可一键恢复原安排；第 7 天周复盘。

**治理**（`src/lib/governance/`）：用户纠错五状态流转、错误结论撤回（留痕+影响范围+通知）、四类通知与偏好开关、13 类数据说明与删除申请。

**数据指标**（`src/lib/analytics/`）：19 事件 + 19 指标统一口径纯函数；静默埋点、会话去重；后台概览含漏斗、积压、异常监控；seed（模拟用户）与 live（真实操作）分开标记。

## 目录结构（精简）

```
frontend/src/
├── app/              # 路由页（含 /admin 子路由、/api 反代）
├── components/       # ui/ layout/ auth/ targets/ evidence/ materials/
│                     # resources/ plans/ governance/ admin/ demo/
├── lib/
│   ├── auth/         # AuthService 接口 + DemoAuthProvider（替换真实认证仅改 instance.ts）
│   ├── targets/      # 目标门禁与查找任务规则层
│   ├── evidence/     # 考情证据 + 可替换 Extractor（setExtractor 接真实 AI）
│   ├── materials/    # 资料诊断规则层
│   ├── resources/    # 资源匹配五层流水线
│   ├── plans/        # PlanEngine / ReplanEngine / 反馈服务
│   ├── governance/   # 纠错/通知/隐私删除
│   ├── analytics/    # 埋点与指标口径
│   └── guest/        # 访客会话 / 轻量结果 / 登录迁移
└── types/            # 跨层共享类型
```

## 关键架构约定

- **认证/用户状态/UI 三层分离**：页面一律经 `useCurrentUser()` 取用户；路由保护用 `RequireAuth` / `RequireRole`。
- **规则层独立**：门禁、诊断、匹配、计划、重排逻辑均为 domain 纯函数，页面不复制判断。
- **Mock 可替换**：认证换 `instance.ts`，AI 提取换 `setExtractor()`，其余服务层已按账号隔离封装。
- **数据诚实**：AI 未审核结论永不标记"已从官方公告核对"；未支持的考试不生成伪精确计划；考情未确认时提示结果可能不完整。

## 设计原则

安静、可信、清晰；浅色背景 + 蓝/绿主色调；不使用排行榜、连续打卡、惩罚性文案；状态同时用文字和图标表达；优先适配手机。
